# PLATING 자동화 지도

2026-11-08 기준. 절차 행 89개(M001~M089). 이번 작업은 지도와 스킬만 작성하며 아래 명령을 실제 미디어에 실행하지 않는다.
W01~W11의 파일명·감사 A/Q 번호는 [감사 보고서](../audit/workflow_audit_2026-11-08.md)를 따른다.

## 명령을 읽는 법

- 현재 수단은 문서의 사람·수작업·도구를 적었다. plating 명령 칸은 현재 코드에 존재하는 대체·보조 수단이다.
- `없음`은 해당 의미 판단·동작을 수행하는 plating 명령이 없다는 뜻이다. 부분 지원은 후보 이유에 한계를 적었다.
- 명령의 `inputs/...`, `out/...`, 씬·클립·프레임 번호는 형식 예다. 실제 파일이나 확정값이 아니다. 먼저 입력을 준비하고 새 출력 폴더를 사용한다.
- 실행 위치는 `C:\Users\uicus\Dev\plating-qc-workflows`, 공식 진입점은 `python -m plating_tools`. 설치 없이 쓸 때 `PYTHONPATH`는 이 저장소 `src`의 절대 경로로 프로세스에만 설정한다. Python 3.12 이상이 필요하다.
- 전역 `--config`는 하위 명령 앞에 둔다. 기본 `plating.toml`과 기존 QC의 `config.toml`은 별개다. 설정 상대 경로는 설정 폴더, CLI 상대 경로는 작업 폴더 기준이다.
- `--out`을 생략하면 설정의 출력 루트 아래 새 실행 폴더를 만든다. 비용 계산만 기본 stdout 출력이다. 입력 부모·raw·읽기 전용 루트·기존 출력에 쓰지 않는다.
- 아래 명령은 `src/plating_tools/cli.py:14`의 parser와 실행 분기, `src/plating_qc/cli.py:15` 및 `tools/plating/README.md`에 대조했다. 이미지 skeleton, manifest 검사, 유료 생성, 업스케일 실행 명령은 만들지 않았다.
- 자동화 후보의 `기존`은 현재 명령 연결, `부분`은 사람 판단과 결합, `신규`는 아직 없는 기능, `사람`은 결정 주체를 유지한다는 뜻이다.
- 우선순위 높음은 승인·원본·중복 비용·버전 사고 예방, 중간은 반복 정리, 낮음은 주관적 연출 보조에 둔다.
- `refs check`는 네트워크 기본 차단이다. URL 미확인 종료 1은 예상된다. 이번 세션은 `--allow-network`를 사용하지 않는다.
- 게이트의 부정문 승인 오판(A01)은 plating-qc-workflows #3에서 고쳤다(2026-11-08). 인용문이 승인 어휘로 끝나고 부정어가 없어야 승인이다. 그래도 종료 0·“승인 기록 있음”은 사람의 생성 승인을 대체하지 않는다.

## 실행 연결과 안전 경계

향후 허용된 작업에서는 `cuts extract` 결과의 cuts.json, 사람이 작성한 plan.toml, `prompt skeleton`의 골격을 연결한다. 사람이 완성한 전문을 `prompt check`에 넣고 별도 refs.toml로 `refs check`를 수행한다. 출력된 check.json·refs.json과 gate.toml을 `gate check`에 전달한다. 매 단계 실제 반환한 새 출력 폴더 경로를 다음 입력으로 사용한다. 고정 경로 덮어쓰기는 하지 않는다.

컷표는 기존 로컬 사본만 사용한다. 이 작업은 노션 사본을 추가 조회하거나 본문을 산출물에 복사하지 않는다. 종료 1은 결과를 읽어 경고·미결을 보고한다. 종료 2~5는 실패이며 새 실행·설치·권한 변경으로 우회하지 않는다. 같은 설정 누락으로 반복될 상황이면 중단하고 원인과 설정 해결안을 보고한다.

`qc convert`는 `--dry-run` 필수다(`src/plating_tools/qc.py:141`). 실제 ProRes 변환을 원하면 별도 미디어 작업에서 기존 `python -m plating_qc`의 경로 정책과 승인을 확인해야 한다. `qc split`은 용량 기준 분할이며 숏 경계 자르기·edit 입력 트리밍 명령으로 안내하지 않는다. `qc compare`의 유사도·정렬은 내용이 의도대로 유지됐다는 판정을 대신하지 않는다.
