## 2. AICRON (MCP + 웹앱)

- 입력은 **공개(링크 보유자) https URL만**. 로컬 파일·비공개 드라이브 파일 불가. 비공개면 "생성에 실패했습니다"만 나온다. 돌리기 전 `curl -sL -o x -w "%{http_code} %{content_type}" URL` → image/*면 OK, text/html이면 비공개.
- 드라이브 공개 폴더의 파일은 `https://drive.google.com/uc?export=download&id=FILEID` 로 쓴다. 루트 폴더가 링크 공개면 하위도 상속. 소유자가 다른 파일은 사용자가 개별로 공개.
- `upload_image`는 짧은 data URI 전용(큰 base64 금지). `prepare_image_upload`는 사용자가 위젯에 직접 올리는 방식이라 혼자서는 못 쓴다(사용자 환경에서 "request sent"로 멈춘 적도 있음). 혼자 할 수 있는 길은 Drive 커넥터 create_file(base64)로 10KB 안팎 JPEG만. 원본 해상도가 필요하면 사용자에게 드라이브 업로드를 부탁하는 편이 맞다.
- **60초 타임아웃이 잦다. 서버는 계속 생성하고 크레딧도 차감된다. 다시 돌리지 않는다.** `get_generation_history`로 prediction_id를 찾고 `check_generation`으로 회수(첫 재호출이 타임아웃나도 한 번 더). 15초 이상 간격. Edit 하나가 4분 걸린 적 있음. 사용자에게 수동 업로드를 부탁하기 전에 이 방법부터.
- 여러 클립을 동시에 보낸다. 오래 안 나오는 클립은 몇 번만 더 보고 실패로 적는다.
- 예약 알림(send_later)은 30~60분 늦게 울린다. 다음 턴에 바로 생성 기록을 확인하는 편이 낫다.
- MCP 기록 도구는 최근 8~12건만. 웹앱에는 MCP 생성 기록 화면이 없다.
- 결과 URL(aicron.delivery)은 다음 edit 입력으로 바로 쓸 수 있다. 결과 webp는 도구 결과(tool-results)에 남는다. aicron.delivery 직접 curl은 프록시 설정에 따라 403(11-05 이후 열림).
- MCP generate_video 입력 = prompt·duration·image_urls·model_id·aspect_ratio. **영상 입력 칸이 없어 video_edit 불가, seed·draft 인자 없음.** image_urls 순서가 곧 @image1, @image2 순서(노션식 `@[이미지 1](image_1)` 표기 안 씀). duration은 숫자.
- 모델 선택은 select_model로. 사용자가 이미 모델을 지정했으면 객관식을 다시 띄우지 않고 choice_map에서 쓴다.
- Crons 잔여를 추정하지 않는다. get_credits로 확인.
- 웹앱 전용: video_edit, 업스케일(쓰지 않음, 06 문서), Topaz.

## 3. Higgsfield (MCP + 웹앱)

- 모델 id: seedream_v5_lite(1 크레딧, 비율 1:1·4:3·3:4·16:9·9:16·21:9, quality basic/high), seedream_v5_pro(2k, is_inpaint), seedream_5_0_flash. 참조 역할 "image_references".
- Seedance: 모델 `seedance_2_5` 하나, mode t2v / omni_reference / video_edit / video_extension. video_edit은 영상 1개를 `video_references`로, duration·aspect_ratio 무시, 과금은 입력 길이.
- 입력: `media_import_url`에 공개 URL → media_id. medias[].value에는 URL이 아니라 media_id.
- `media_upload` PUT(upload.higgsfield.ai): 10-28 프록시 403 → 10-30 통과(헤더 Content-Type과 `If-None-Match: *` 필요) → 10-31 다시 차단 → 11-05 Allowed domains 추가 후 미재확인. 쓰기 전에 매번 확인.
- 결과 도메인 `d8j0ntlcm91z4.cloudfront.net`은 11-05부터 접속됨(이전 차단).
- 무제한(unlim) 모드: 계정 ultra 플랜이지만 MCP에서 available=false → use_unlim 거부. 웹앱 토글이 MCP에 적용되는지 미확인. 크레딧 차감이므로 생성 전 승인.
- upscale_video의 topaz는 프리셋·fps 칸 없음 → 업스케일은 웹앱에서 사용자가(06 문서).
- Draft Mode(480p 초안 → 1080p 재렌더): 크레딧 없어 안 쓴다.
- 시대·장르·조명·물리 선택 메뉴는 비워 둔다(프롬프트 빛 설명과 충돌). Seedance 2.5는 스코어를 자동 생성 → 음악 금지를 세게.
- 11-03 사용자: Higgsfield 크레딧 없음, 이미지·영상 생성은 AICRON으로. 이 절은 경로 기록용.

## 4. 클라우드 컨테이너 (Claude 스레드)

- 외부 접속은 프로젝트 클라우드 환경의 Allowed domains로 결정. 환경이 선택되지 않으면 기본 환경으로 돌아 drive.google.com·aicron.delivery·upload.higgsfield.ai·cloudfront 전부 프록시 403(10-31). 해결은 Project settings > Cloud environment에서 도메인 추가(11-05 해결). "서버 자체 응답"인지 "프록시 차단"인지 구분해 보고.
- claude.ai 공유 링크는 클라우드에서 Cloudflare 403. PDF·텍스트로 받는다. 아티팩트는 로그인 필요라 Codex는 못 받는다.
- 한글 PDF는 pymupdf(없을 수 있음) 또는 pdftotext. Read·pdftotext로 글자가 깨지면 다른 방법.
- 드라이브 커넥터는 텍스트 파일만 올린다(base64 텍스트). 이미지·영상은 직접 못 올린다. Higgsfield 업로드는 "Data Exfiltration"으로 거부된 적 있음.
- 코드로 고친 파일을 사용자에게 주는 길: 아티팩트에 원본 해상도 파일 + 다운로드 버튼(02 문서). PC가 크롬으로 아티팩트를 열어 받아 G 드라이브에 넣는다.
- 이미지 처리 라이브러리는 PIL·numpy만(cv2·skimage 없음). 한국어 폰트는 npm pretendard 패키지(웹 폰트 CDN은 프록시 차단).
- Blender bpy는 컨테이너에 설치하지 않는다. Workbench만 되고 유리가 불투명 파란 면으로 나온다.
- 프로젝트 공유 폴더 한도 10GB. 첨부 약 400MB까지(660MB 실패). 네트워크 마운트라 쓴 뒤 약 10초 후 다시 읽어 확인.
- 아티팩트 안 이미지는 1600px 축소본, 4MB쯤부터 수정 불가.

## 5. 사용자 PC (Remote Control)

- 폴더는 스레드를 만들 때 지정. 승인 폴더 `D:\Plating`, `G:\내 드라이브\RAPA-NS_PLATING`.
- 클라우드 스레드가 같은 스레드의 PC 세션에 지시할 때는 `start_remote_control`의 instructions에 넣는다(이미 돌고 있으면 "delivered"). SendMessage나 스레드 글은 PC에 닿지 않는다(11-02).
- 자동 모드가 드라이브 업로드를 "Unrequested Commit in a Connected App"으로 거부한다. 다른 스레드의 요청이면 거부, 사용자가 그 스레드에서 요청하면 통과(11-06). 사용자 상시 허락(AICRON 입력용 중간 파일은 공개 폴더에 올려도 됨, 11-02)을 지시에 메시지 id로 붙인다. G: 쓰기 허용 규칙은 사용자가 PC Claude Code에 추가해야 함(미결).
- PC PATH에 ffmpeg 없음(BlueStacks 번들뿐) → Blender 내장 FFmpeg.
- Blender 5.2 LTS, PATH에 없음. Action에 fcurves 없음(keyframe_delete 사용).
- `[예외: 11-06 분담]` PC 영상 작업은 "영상 ProRes 변환·검수" 스레드, Blender는 연회장 스레드. 변환 결과는 PC가 `G:\내 드라이브\RAPA-NS_PLATING\00 VIDEO\<씬>\`에 저장.
