# 검수 및 1차 구현 범위

Claude 프로젝트의 03 설계는 `probe`와 `convert`부터 구현한다. 설계는 파일 존재 확인 후 이름 변경을 기술하지만 동시 실행 중 이름이 만들어지는 경합이 있어, 임시 파일을 같은 폴더에 만들고 최종 경로에 하드링크를 원자적으로 생성한다. 파일 시스템이 하드링크를 지원하지 않으면 안전하게 실패한다. 실패한 임시 파일은 제거한다.

표준 라이브러리만 쓰기 위해 테스트는 pytest 대신 unittest를 사용한다. FFmpeg 인코더·디코더를 합성 입력으로 검증한다. Windows와 동기화 드라이브의 하드링크 지원 여부는 해당 환경에서 확인해야 한다.

프레임 속도 의심은 현재 두 ffprobe 속성의 차이만 보고하는 부분 검사다. PTS 간격 분석, genpts 복구, 로그 파일, Blender 폴백은 미구현이다. 변환 결과가 필수 검증을 통과하지 못하면 최종 파일을 남기지 않는다. 형식적 검증은 화면·색의 시각적 동등성을 보장하지 않는다.

## 비교와 타일의 1차 구현 차이

비교는 64×36 회색 영상의 표본 평균 절대차를 사용한다. 반복 장면, 프레임 속도 차이, 낮은 유사도는 불확실로 표시하고 누락 수치 확정을 피한다. 밝기 정규화, 시간 기반 VFR 정렬, 중간 프레임 손실과 합성 혼합 프레임 자동 판정은 아직 없다. 탐색 범위 밖의 오프셋은 찾지 못한다. 정렬 결과는 근거 확인용이며 눈으로 원본과 대조해야 한다. 대용량 비교는 메모리 제한으로 거부할 수 있다.

타일은 새 출력 폴더에만 저장한다. `raw/` 출력과 기존 폴더 덮어쓰기를 막는다. 프레임을 선택하기 전에 0 기반 디코딩 번호와 원본 PTS 초를 그린다. 선택 프레임의 PTS와 시간 기준을 manifest에 기록하고 누락·중복으로 원본 식별이 불가능하면 출력을 거부한다. FFmpeg drawtext·글꼴이 필요하며 100000프레임을 넘는 입력은 거부한다. `compare --out`은 새 폴더에 JSON·텍스트 보고서와 정렬된 쌍의 좌우 이미지를 최대 10장 저장한다. 정렬이 불확실하면 보고서만 저장한다. 장면 전환 후보 자동 감지는 미구현이다.

## Windows 테스트 후 수정

`convert`와 `tiles`가 같은 layout 검증을 사용한다. 경로 구분자가 든 `raw` 설정은 출력 전에 거부한다. 타일은 새 출력 폴더의 임시 폴더에서 생성하고, FFmpeg에 경로 없는 파일명만 넘겨 부모 경로의 `%`가 패턴으로 해석되지 않게 한다. 성공한 파일은 덮어쓰기 없는 하드링크로 배치하고 실패 시 임시 파일과 이 실행에서 배치한 파일을 정리한다. 커밋 0ebea80까지는 Windows C: 임시 폴더에서 확인됐다. 이후 변경 및 D:·동기화 드라이브는 재검증이 필요하다.

## ProRes 분할 1차 구현

ProRes만 스트림 복사 방식으로 분할하고, 사용자 지정 크기를 모든 조각이 지키는지 확인한다. 원본과 이어 붙인 각 조각의 모든 디코딩 프레임 해시가 일치할 때만 새 폴더에 배치한다. 예측 크기보다 조각이 커지거나 검증에 실패하면 결과를 남기지 않는다. 오디오 경계 및 편집기 재생은 검증하지 않는다. VFR 의심 영상은 거부한다. Windows 하드링크 및 D:·동기화 드라이브 검증은 남아 있다.

## 분할 오디오 경계 검증

Windows C: 임시 폴더의 커밋 9b01ddd 합성 테스트에서 48프레임은 14/14/14/6으로 보존됐다. 48kHz PCM 96,000샘플도 전체 보존됐으나 조각별 오디오 시작이 0/14.000/6.667/20.667ms였고 일부 오디오·컨테이너 길이가 영상 경계를 넘었다. Linux의 별도 48kHz PCM 합성 예제에서는 복원된 PCM을 순서대로 이어 붙였을 때 바이트가 원본과 같았지만, 패킷 간격은 주로 1024샘플(21.333ms)이고 영상 경계와 일치하지 않아 시작 위치·길이가 조각마다 달랐다. 이 실험은 다른 코덱과 편집기에서의 이음새를 보증하지 않는다.

기본 동작은 기존 스트림 복사를 유지한다. 오디오가 있으면 `manifest.json`과 CLI에 첫 번째 오디오 스트림 및 영상 시작·길이를 기록하고, 이음새 미검증 경고와 종료 코드 1을 반환한다. 영상 검증을 통과한 출력은 저장된다. 원본 오디오를 연속 트랙으로 두는 방법을 편집기에서 검토할 수 있지만 실제 이음새 검증이 필요하다. 여러 오디오 스트림의 시간 정보 전체는 표시하지 않는다.
