## 변경 내용

PLATING 영상 검수·변환 CLI에 FFmpeg 백엔드와 `MediaInfo` 모델을 적용했습니다. probe·convert·compare·tiles·split 명령을 제공하며, 프레임 정렬, 밝기 정규화, ProRes 사후 검증, 충돌 방지 저장, 타일·장면 후보, 분할 프레임 검증과 JSON 실행 로그를 지원합니다.

09 검수에 따라 명령 내부에서 `MediaInfo`를 유지하고 JSON 출력 시 직렬화합니다. 실행 계획은 백엔드 명령 목록이 아닌 설명 문자열로 제공하며, 경고는 불변 튜플로 보관합니다. 능력별 백엔드 인터페이스 분리는 Blender 백엔드를 붙이는 11/11 이후로 연기했습니다.
