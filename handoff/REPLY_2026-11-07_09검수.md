## 구조 수정·검증

- `MediaInfo`를 명령 내부에서 사용하고 JSON 경계의 공통 `json_default`에서 직렬화한다. `warnings`는 튜플이다.
- `MediaBackend.prores_command`를 `describe_prores` 문자열 계약으로 교체했다. 능력별 인터페이스 분리는 `design/plating-qc.review.md`에 11/11 이후로 명시했다.
- 평탄 프레임은 기존 `tests/test_compare.py::CompareIntegration.test_compare_repeated_frames_is_uncertain`이 정적 검정 영상을 다뤘다. 이번에 `CompareTests.test_flat_frames_use_original_brightness_distance`를 추가해 분산 0일 때 원래 밝기 차이를 쓰는 동작을 직접 검증했다.
- 테스트 자동 로그는 `PLATING_QC_LOG_DIR`로 임시 폴더에 지정한다. 기존 루트 로그는 53개였으며 전체 테스트 전후 53개로 유지됐다. 삭제하지 않았다.
- `a16779d`: Windows 전체 테스트 66건 통과, 실패 0, skip 0. 로그 `handoff/logs/win_a16779d_2026-11-07_171401.txt`. 합성 예제 다섯 명령 종료 0, `samples/README.md`와 `handoff/logs/synthetic_09/` 참조.
- 구조는 09 지시대로 여기서 동결한다. 실제 클립은 이 구조 수정 이전에 검증했으므로 수정 후 실제 클립 재검증과 편집기 재생·오디오 동기화는 미확인이다.

## 실행 환경과 설치

09의 사후 승인 전, 앞선 작업에서 uv 0.13.7을 임시 폴더에 내려받고 SDK 0.125.0을 uv 사용자 캐시에 설치했다. **무단 설치 예외 있음.** 09에서 사후 승인됐지만 당시 자가 점검에 누락한 것도 위반이다. 이번 작업에서는 설치하지 않았고 임시 uv를 실행하지 않았다.

09가 사용자 영역 SDK 설치 완료라고 기록한 `C:\Users\uicus\AppData\Local\Programs\Python\Python312\python.exe`를 이 환경에서 확인한 결과 `anthropic` 모듈이 발견되지 않았다. 기본 샌드박스와 권한을 높인 확인이 모두 동일했다. `tools/README.md`는 지시대로 `python tools/claude_design.py ...` 명령으로 갱신했지만 SDK가 현재 Python에 보여야 실행된다. 사용자 환경 확인이 필요하다.

## PR과 후속

`handoff/PR1_BODY.md`에 PR #1에 붙여 넣을 본문을 작성했다. PR은 결과 검수 전 병합하지 않는다. 기존 `plating-qc-logs/` 53개는 사용자 확인 전 삭제하지 않는다.

실제 영상에서 파생한 PNG와 검증 자료를 GitHub로 보내는 push는 자동 승인 심사에서 거부됐다. 이유: 해당 민감 자료를 그 목적지에 공개하는 명시적 승인 근거가 부족하다는 판단. 로컬 작업과 커밋은 보존했으며 원격 전송은 하지 않았다.
