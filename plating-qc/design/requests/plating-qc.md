# PLATING 검수·변환 도구 설계 요청

## 목적과 상태
11월 11일 PLATING 제출을 우선 지원하는 독립적인 오프라인 검수·변환 도구의 설계를 검토해 주세요. 이 문서는 Codex가 작성한 요청 초안이며 Claude 설계나 검수 완료 결과가 아닙니다. 실제 구현은 설계 검수 뒤 시작합니다.

- 2026-11-07 GitHub main 기준 커밋: NS-Plating `577c3d4cc607c823603fe1aa0e78fa02773a8e33`, sangsang-voice `0b4b655b3122a48a2a394ad8bbfa85b61c6397eb`, CMMI_Blog `c927279ba478a1e678e1d4e039343dee802f8153`. 이후 변경될 수 있습니다.
- Drive의 2026-11-07 핸드북 사본: https://drive.google.com/file/d/1Qw46FiidfLhD8ZfNEM7Ss_tXmJ6K5fir/view . 0-1부와 5-10, 5-12, 5-13을 참고했습니다. Notion 페이지의 현재 첨부와 동일한지는 검증하지 못했습니다.
- Linux 실행 환경에 ffmpeg/ffprobe 7.1.5, Python 3.12.14, Node 24.22.1, npm 11.9.0이 있습니다. bun과 pytest는 발견되지 않았습니다. 환경은 읽기 전용이므로 클론 및 기본 테스트는 미실행입니다.
- 이 Windows 컴퓨터에서도 `D:\Plating`을 사용 중이라는 사용자 설명이 있습니다. 읽기 전용 점검에서 Blender 씬·블록아웃, 렌더 스크립트, 숏 README, HTML 핸드북과 ProRes 도구가 확인됐습니다. 루트와 1단계 하위에서 `.git`은 발견되지 않았고 Git 상태 확인은 권한 거부로 실패해 저장소 여부는 미확인입니다. 우회하거나 기존 파일을 덮어쓰거나 이전하지 않습니다.

## 요청하는 설계
1. 원본과 업스케일본의 실제 디코딩 프레임 수, 해상도, 프레임 속도를 비교합니다. 원본이 없으면 누락을 확정하지 않습니다. 결과를 원본 크기로 줄여 같은 프레임끼리 살펴보고 어긋나는 구간 및 앞·끝 누락을 검토할 수 있게 합니다. 프레임 수가 같다는 사실만으로 내용이 같다고 판정하지 않습니다.
2. 검수용 1초 간격 타일(예: 폭 320픽셀, 5×2)과 지정 컷 경계 주변 프레임을 추출합니다. 긴 영상은 여러 장으로 나누고, 컷·빠른 이동·혼합 프레임의 최종 판정은 사람이 합니다.
3. 입력을 ProRes 422 HQ로 변환하고 실제 프레임 수, 해상도, fps, 프로파일, BT.709 색 기본값·전달·색공간 태그를 확인합니다. 음성이 짧아도 영상 끝이 잘리지 않게 하며 오디오가 없는 경우도 처리합니다. 원본 및 기존 결과를 덮어쓰지 않습니다.
4. 결과는 원본과 같은 씬의 `prores/` 폴더 및 원래 이름 기반 접미사 규약을 고려합니다. 위치와 충돌을 먼저 확인합니다. 큰 출력 분할과 경계 프레임 검증은 별도 선택 기능으로 제안하고 경험적 크기를 확정 한도로 취급하지 않습니다.
5. 명령별 실키 없는 테스트와 재현 가능한 샘플 로그를 포함합니다. 데이터와 미디어는 로컬에서 처리하며, 별도 승인 없는 유료 생성 API 및 외부 공유는 하지 않습니다.

## 설계 답변 형식
- CLI 인터페이스와 입력·출력 계약, 파일 트리, 데이터 흐름, 오류·종료 코드.
- 프레임 수 산정 방법과 가변 프레임 속도, 손상된 파일, 없는 타임스탬프, 오디오 유무·길이 차이에 대한 검증 한계.
- 임시 파일, 실패한 부분 출력, 이름 충돌 및 경로 처리 방안.
- 자동 테스트에 사용할 합성 입력과 각 테스트의 검증 조건. 실제 촬영물이나 실키는 사용하지 않습니다.
- 추후 컷표 파서, 프롬프트 골격, 점검 게이트, 레퍼런스 및 버전 검사와 연결할 경계. 정본 핸드북의 고정 블록이나 수치를 코드에 복사해 고정하지 않습니다.
- 불확실한 점과 사용자 확인이 필요한 사항을 별도로 표시해 주세요.

## 결정과 접근 제한
- 핸드북·시나리오의 Notion 본문과 CMMI `specification/`, `/source/*.pdf`를 수정하지 않습니다. 기본 목소리와 영어 대사는 사용자 결정 전 변경하지 않습니다.
- [Notion 작업 핸드북](https://app.notion.com/p/3cc339339b9b81f798fde53748ed37c0)은 학교 계정 연결로 읽을 수 있음을 확인했습니다. 처음 확인한 다른 계정에서는 404가 반환됐습니다. 페이지 상단에는 같은 이름의 11월 7일 전체판이 최신이라고 표시되어 있지만 Drive 사본과 바이트 일치 여부는 미확인입니다.
- 새 도구용 비공개 저장소 `tacosangsang/plating-qc-workflows`가 생성되어 있습니다. GitHub 연결로 접근 가능하지만 이 실행 환경의 GitHub CLI는 로그인되지 않았습니다.
- Claude Messages API의 실제 모델 ID, 크레딧 적용 범위, 만료시각과 승인된 비용 한도는 미확인입니다. API 키를 문서·채팅·저장소에 넣지 않습니다. 승인 및 조건 확인 전 호출하지 않습니다.
- 기획서 패키지는 사용자의 문서 최신화 완료 확인 후 시작합니다.
